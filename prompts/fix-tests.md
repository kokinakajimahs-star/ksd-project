# タスク: 検証器が通るまで収束させる

このリポジトリの検証器（`scripts/verify.sh`）が PASS する状態にすること。

## 完了の定義

- `bash scripts/verify.sh` が exit code 0 で終了する
- テストが削除・スキップ・弱体化されていない
- しきい値・型検査・lint の設定が緩められていない
- 変更が、失敗の**根本原因**に対応している（症状の握り潰しではない）

## 進め方

1. **編集する前に**、検証器の出力を全文読み、失敗しているケースと通っているケースの差を特定する。
2. 該当箇所の周辺にある既存の実装パターンを読む。
3. 最小の一貫した修正を 1 つ行う。ついでの整理・リネーム・最適化を混ぜない。
4. 最も狭い関連テストを実行する。
5. 通ったら全体の検証を実行する。

## 制約

- 公開 API を変えない（明示的な依頼がある場合を除く）
- 既存のスタックで妥当に解けるなら依存を追加しない
- `git push` / PR 作成 / デプロイ / 本番データへの操作は行わない
- 秘密情報を読まない・書かない

## 判断に迷ったら

製品仕様やセキュリティの判断が必要だと考える場合は、**変更を加えずに**その理由を書くこと。
推測で本番値を確定しないこと。
