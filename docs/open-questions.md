# Open Questions（未確定事項）

要求仕様書（`docs/pmt-requirements.md`）11 章の未確定事項を、実装ループで扱える形（Status 付き）へ移したもの。
正は要求仕様書 11 章である。確定したら要求仕様書と設計書の更新を Change Request として起票する。
**未確定事項は実装を止める理由にしない。**
抽象化・外部設定化・未指定なら fail fast・ここへ記録、の 4 点セットで実装を完了させる。

Status: `OPEN`（未確定・暫定実装なし）/ `ASSUMED`（暫定設計で実装済み）/ `CLOSED`（確定）

**本番値を独自に確定してはならない。** 確定は要求元の判断による。
