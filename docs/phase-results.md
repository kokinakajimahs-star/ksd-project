# Phase Results

各ループ（タスク）の完了時に追記する。**これは報告であって質問ではない。**
出力後、応答を待たずに次のスコープへ進む。

## 書式

```markdown
## <タスク名> Result

- 日時: YYYY-MM-DD HH:MM (JST)
- run_id: run_...
- 終了状態: SUCCESS / BLOCKED_* / ...
- 未実装 ID: 開始 N 件 → 終了 M 件
- 実装したもの: <ファイル・機能>
- 検証: <実行したコマンドと結果>
- 未達・残課題: <あれば。無ければ "なし">
- 追記した Open Question: <Q-xx。無ければ "なし">
- 起票した CR: <CR-xxx。無ければ "なし">
- 次のスコープ: <次のタスク>
```

---

## 環境構築 Result

- 日時: （`kloop bootstrap` を実行した日）
- 実施内容: 設計書からの実装環境の構築（実装そのものは未着手）
- 検証: `bash scripts/verify.sh all` の初期値を記録すること
- 次のスコープ: （最初のタスク）
