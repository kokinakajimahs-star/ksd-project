# R2 以降の要望（控え）

R1（要求仕様書 5 章・設計書 1.3）の範囲の外にある、利用者の要望を控える。ここに置いても実装しない（要求仕様書 2.1：R1 の範囲で R2・R3 の機能を
前提にした作りにしない）。

そのリリースの着手時に、要求仕様書 6 章（R2・R3 の一覧）へ足すか、既存の機能 ID に含めるかを決め、受入基準を書き下ろす。要求仕様書と設計書は保護パス
なので、改訂はそのときに利用者の承認を得て行う。Change Request（`docs/instruction-change-requests.md`）は「設計書どおりでは成り立たない」ときに
限るので、将来の機能の要望はここに置く。
